The JSON Schemas do not attempt to encode the entire semantic model.

That is intentional.

agent.json expresses Agent identity and package metadata.

SKILL.md expresses the portable behavioral projection derived from the Behavior Flow.

actions/ contains executable capability boundaries.

knowledge/ contains Evidence, Wiki, and Evolution state.

mcpq.json expresses Agent communication channels.

Behavior Flow, AtomicSkill, AtomicBehavior, Intent, Trajectory, and the full semantic source model remain implementation- or DSL-level artifacts in this draft. A future version may define a canonical machine-readable Behavior Flow schema once its semantics are fully formalized.

The specification text is authoritative if its requirements conflict with a machine-readable schema.

The current schema URLs are draft repository identifiers. They are not yet immutable publication identifiers. Once version 1.0.0 is published, its identifiers MUST become immutable.
