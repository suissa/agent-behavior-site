Agent Behavior is a specification, not a requirement that every runtime expose the same user experience.

A compatible runtime can adopt the model incrementally:

1. Agent package and root SKILL.md.
2. Action discovery.
3. Queue-first MCPQ.
4. Persistent knowledge and validation-gated evolution.
5. Optional MCP interoperability.

The compatibility matrix should describe actual implementation support, not theoretical support. A runtime SHOULD identify which parts of the specification it implements and which remain unsupported.
